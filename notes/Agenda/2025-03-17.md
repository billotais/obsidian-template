## Tasks

> [!multi-column]
>
>> [!danger] Overdue
>> ```dataview
>> TASK
>> WHERE (due) AND !completed AND (due < date(this.file.name))
>> GROUP BY header
>> ```
> 
>> [!caution] Due Today
>> ```dataview
>> TASK
>> WHERE (due) AND !completed AND (due = date(this.file.name) )
>> GROUP BY header
>> ```
>

> [!multi-column]
>
>> [!todo] Due Next Week
>> ```dataview
>> TASK
>> WHERE (due) AND !completed AND due > date(this.file.name) AND (due <= date(this.file.name) + dur(7 day))
>> GROUP BY header
>> ```
>
>> [!success] Done Today
>> ```dataview
>> TASK
>> WHERE completion != null AND completion = date(this.file.name)
>> GROUP BY header
>> ```
